# Backend AquaChile · EA3

API Express sobre Node.js 24, con Mongoose, JWT y Swagger UI. Desde este directorio, instala con `npm ci`, copia `.env.example` a `.env` y configura una base ficticia en MongoDB Atlas o un replica set local. `npm run dev` inicia la API. `npm start` sirve la versión de Render.

- **Documentación interactiva** · `http://localhost:4000/api/docs`.
- **Pruebas** · `npm test` o `npm run test:cobertura`. La suite inicia su propia base temporal y usa Gemini simulado.
- **Configuración, roles, almacenamiento y deploy** · [Guía EA3](../docs/guia-ea3.md).
